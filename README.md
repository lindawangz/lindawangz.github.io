# Portfolio Starter

A responsive, single-page portfolio starter inspired by the supplied references: sage-green editorial hero, minimalist project grid, airy layouts, pill navigation, and lime accent details.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. Google Fonts are loaded online; system sans-serif fallbacks are included.

## Personalize

Search and replace the sample content in `index.html`:
- `LINDA WANG` and page title
- Introductory paragraph and role
- Project titles, descriptions, categories, and visual mockups
- Experience and education entries
- `hello@example.com`, LinkedIn, and GitHub links

The project artwork is made with CSS UI mockups so the starter works without external image files. Replace those visual blocks with real screenshots or device mockups when available. Sample projects and credentials are placeholders and should be replaced with accurate information.

- `mending-kids-case-study.html` — Mending Kids medical inventory case study.
